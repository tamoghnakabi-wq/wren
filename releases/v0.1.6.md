- Security: on macOS, Claude Code and Grok Build now run inside Wren's sandbox, so the commands they run can only reach the folders you allowed (plus their own sign-in state).
- Security: agent commands no longer read shell startup files or credential files such as `~/.npmrc`, `.pypirc`, `.netrc` or `.git-credentials`, and can't read `/Users/Shared` or external drives unless you allow them. Developer tools keep working.
- Security: file reads and writes by the agent go through the same sandbox, so a folder swapped for a link can't redirect them outside your allowed folders.
- Changing "This computer" settings now applies to tasks that are already running. Removing a permission stops commands started under it; Claude Code and Grok runs end and can be continued with a message. Removing every folder now really leaves none.
- Background commands belong to their task: they stop when the task finishes or you press Stop.
- On Windows, where commands can't be sandboxed, every command asks for approval unless the agent is Autonomous.
- Signing out of ChatGPT takes effect immediately, even while a token refresh or another sign-in is in progress.
- Updates are verified again from a private copy right before they're installed, and prerelease versions are ordered correctly.
- Fix: a tool used through Claude Code could show twice, with one copy stuck on "running".
