- Wren starts Claude Code and Grok Build only from places agents can't change, and now checks this every time it runs them, including when it only asks for their version. It no longer runs your login shell to find them.
- Claude Code's own file tools can no longer change its installed program, and agents can't change the folders on your PATH (such as ~/.local/bin), even when you've allowed your whole home folder. tcsh's startup files are protected too.
- Starting a new Sign in with ChatGPT now always wins over an earlier one still finishing. Signing out stops Wren using the old sign-in even if it can't be removed from disk, and Wren tells you if that happens.
- One task can no longer read another task's background command output.
- If a page puts typed text back into a field after Wren took it out, Wren checks again and removes it.
- Deleting a home folder or a whole drive is also blocked when the paths are given as a PowerShell array (@('…','…')), and options such as -Confirm no longer count as "recursive".
