- Security: agents can no longer read or change Wren's own settings and data through their file tools, even when you've allowed a folder that contains them (most important on Windows).
- If the agent browser won't close for an update, Wren now stops it itself instead of trying again forever, and never assumes it closed when it didn't.
- When a task ends, permission requests still on their way are called off too.
- Grok Build: if it fails to start, nothing is left behind.
- A step whose approval was withdrawn (the task stopped) now shows as stopped, not as denied by you.
