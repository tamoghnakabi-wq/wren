- Security: `git status`, `git diff`, `git log` and similar commands now count as able to change files, because a repository's own settings can make Git run programs (hooks, filters, diff tools). In Careful mode Wren asks before running them. Commands that only read branches, tags and settings still run without asking.
- Security: a `PAGER=…` in front of a command no longer counts as harmless: it chooses a program to run.
- Security: a key combination like Shift+Enter is guarded until its last key reaches the checked element. A page can't use the first key to move focus to another button. If Wren can't confirm where the key went, it says so instead of reporting success.
- Security: before typing, Wren checks that the field is still the one it checked. If the page turns it into a password field when it's clicked into, nothing is typed.
- Updates: if you open Wren while an update is still installing, it leaves the installer alone and the new version opens when it's done.
