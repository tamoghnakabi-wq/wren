- Security: more commands that look harmless now count as able to change files, because an option or a project file can make them run a program: `man -P …`, `sort --compress-program …`, and version checks like `cargo --version` or `node --version`, which version managers can point at a program in the project. In Careful mode Wren asks before running them.
- Security: a page can't fake a key press. Wren only counts real key events that match the keys it pressed, so it reports a key it couldn't confirm instead of claiming success.
- Security: before typing, Wren checks everything a field is called (its title, its label, placeholder and more). A field that turns out to be for a password or card number gets nothing. If a page changes a field while Wren types into it, the old text is put back, including in rich-text editors.
- Updates: if Wren can't tell whether an update is still installing, it leaves the installer's files alone instead of deleting them. A problem recording the installer no longer stops the update from going ahead.
