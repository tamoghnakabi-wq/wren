- Security: commands your agents run no longer see Wren's own environment. If you started Wren from a terminal where tokens or keys were set (GitHub, cloud, AI providers), agent commands can't read them, and settings like a shell startup file or pager can't make a command run something else. Claude Code and Grok keep only their own sign-in settings, and Claude Code's commands are stripped back the same way.
- Security: a field whose name or id marks a password, one-time code or token is never typed into, and labels split over several lines are read correctly.
- Security: shortened option names (like `sort --o=…` for `--output`) count the same as the full ones when Wren decides whether a command can change files.
- Key presses written as a newline count as Enter.
- Updates: Wren recognises an update that's still installing even if it couldn't record everything about the installer, so it never deletes the installer's files.
