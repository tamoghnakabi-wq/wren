- If this computer is removed from your Wren account on the web, it now stops its running tasks straight away, signs out and tells you. Before, only new tasks stopped.
- Unlinking only counts as confirmed when Wren's own server says so. If Wren can't confirm it, or can't keep a record to try again, it tells you which.
- Linking survives a slow connection: if the answer gets lost on the way, Wren asks again and gets the same link instead of failing.
- A link that was saved stays linked even if starting work right after fails.
