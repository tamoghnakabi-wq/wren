- Agents ask before any GitHub repository change that isn't an ordinary one (issues, pull requests, files, releases, labels, running CI). That covers repository settings, Actions administration such as self-hosted runners and OIDC, and endpoints GitHub adds later, even for agents set to autonomous.
- Cloud agents can no longer pull a huge file into Wren's servers: reading stops at 8 MB, editing at 5 MB and sharing at 50 MB. Sharing a file from your computer is now limited to 50 MB too, the most Wren stores.
- Setting up an authenticator app can't get stuck: if a step takes too long, Wren stops waiting and shows what actually happened.
- A stopped task's connected (MCP) tool call now also gives up while it's still checking the task, not only while connecting.
