- Wren keeps this computer awake while an agent works on it, and for a minute after, so a long task isn't cut off by sleep. The screen can still turn off, and closing a laptop's lid can still put it to sleep. Turn it off in Settings → This computer → Stay awake while agents work.
- Deny with a reason: when an agent asks to do something, you can say why not or what to do instead, and the agent is told.
- Agents now read the text files you attach (up to 1 MB each), not only their names.
- Pasting a long text (over 10,000 characters) attaches it as a file, so your message stays short and readable.
- In an empty message box, ↑ brings back the last message you sent in that task.
- A link can fill in a message for you: /app?prompt=…&agent=… opens Home with the text in the box. It is never sent until you send it.
