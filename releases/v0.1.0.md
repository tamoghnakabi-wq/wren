First preview of Wren for macOS and Windows.

- Link your computer to your Wren account in one click.
- Agents work on your computer inside folders you allow; on macOS shell commands are OS-sandboxed.
- Use your ChatGPT plan (Sign in with ChatGPT), Claude Code or Grok Build with your own logins, local models (LM Studio, Ollama), or API keys.
- Approve sensitive actions from your phone or this computer.
- Signed automatic updates.

Preview builds are not yet signed with an Apple Developer ID or Windows code-signing certificate; see the download page for first-launch steps.
