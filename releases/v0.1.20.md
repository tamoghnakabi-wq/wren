- Security: turning on terminal commands, the browser, screen capture or approvals from other devices now asks you in a Wren dialog on this computer. Turning them off doesn't.
- Security: linking this computer asks you to confirm the account it's being linked to. A linked computer has to be unlinked before it can be linked to another account.
- If the agent browser won't close, Wren stops only that browser and everything it started. It no longer goes by command lines that merely look similar. Quitting and updating stay responsive while it does this.
- Files left behind by an engine run that crashed are cleared when Wren starts.
- Wren's own folders are left out of file listings on macOS too.
