- Agents can now ask each other. In an agent's Settings, switch on "Other agents it can ask", and it can put a question to them in the middle of a task: a Claude Code agent can ask your OpenAI or Grok Build agent, and the other way round. The agent it asks works on the question as its own task, with no more freedom than the agent that asked, and the answer goes back into the first task.
- While an agent waits for an answer, its task shows who it is waiting for, with a link to that agent's task. Stopping the task also stops the agent it asked.
- Claude Code agents ask through a new ask_agent tool. Grok Build agents can be asked but can't ask others yet.
