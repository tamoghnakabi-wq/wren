- Security: unlinking this computer now also cancels its sign-in with Wren, so it stops working everywhere straight away. Declining a link on this computer gives the sign-in back too.
- Linking is more reliable: Wren no longer loses a link that was approved while it was still checking.
- If the agent browser won't close, Wren now recognises it by its start time, so it never stops another program that has since been given the same process number. A browser that closes while Wren is still identifying it is no longer forgotten.
- File listings on macOS now show your files even when a folder also contains Wren's own folders.
