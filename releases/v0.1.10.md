- Security: a command like `ls` counts as harmless only when it runs the usual program. If a folder agents can write to comes first on your PATH, it could be something else, so Wren asks first. Agent commands can no longer write to pnpm's global folder (only its package store).
- Security: which page element a browser action reaches is now decided in a part of the browser that web pages can't touch. A page can't make one button stand in for another, or change what Wren reads about an element or the page.
- Security: typing only goes into the field that was checked. If clicking into a field moves focus somewhere else (a password box, say), nothing is typed, and a label can't be typed through to the field it names. For a key press, focus is held on the checked element until the key arrives.
- Closing a task now also closes the popups it opened. If one won't close, Wren closes the agent browser rather than leave it running.
- Anything a command leaves running (`server &`) is tracked until it has really stopped, so stopping a task, quitting or updating reaches it. On Windows each command runs in its own job, so what it starts ends with it.
- Quitting Wren waits (up to 15 seconds) for tasks and commands to stop.
- Updates: Wren quits for an update only once the installer is running. If an update doesn't install, Wren says so the next time it starts, and on a Mac the previous version is put back and reopened.
- Windows: file writes refuse links and junctions, but a folder swapped at the very moment a file is created can still leave an empty file outside your folders. Only a program already running with your full access could do that.
