- Security: Claude Code now runs in its restricted mode. Your personal Claude settings and MCP servers don't apply to Wren tasks, its file tools stay inside your allowed folders, and every command it runs is sandboxed without access to the Keychain or Claude's own settings.
- Security: commands run by Grok Build can no longer change Grok's hooks, settings, trusted folders or plugins.
- Security: browser approvals are tied to the exact element on the exact page you approved, and each task uses its own browser tab.
- Security: quoted command options (for example `sort "-o" out.txt`) are judged the way the program sees them.
- Security: updates are prepared in Wren's own data folder, which agent commands can't touch, and agents stop before an update is prepared.
- Wren's file tools only read your allowed folders (and the system files they need); listing folders is sandboxed too.
- Turning off remote approvals also applies to approvals that are already waiting.
- Stopping a task now force-stops commands that ignore the first request to stop.
- A message you send while the agent is finishing its answer now gets its own reply.
- Claude Code: Wren now needs a recent version; if you see "too old", run `claude update`.
