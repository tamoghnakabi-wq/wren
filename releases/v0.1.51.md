- Security on Mac: commands an agent runs can no longer read or change your clipboard, capture your screen, or run your Shortcuts. Each of these happened outside Wren's sandbox: the clipboard can hold a password you just copied, and a screen capture could go past the screen setting in Wren and its approval. Agents are told to use a file, Wren's screen tool or ask you instead.
- If you remove a folder from the ones agents may use, containers an agent started with that folder are stopped too, so nothing keeps using it.
- Docker through Wren is stricter about unusual spellings in container settings and build options, and keeps its command-line settings in a folder agents can't change.
- Electron 44.11.6, with backported Chromium, V8 and PDFium security fixes.
