- Pressing Enter by another name ("\n" or "\r", which the browser treats as Enter) on a button such as "Place order" now asks first, exactly like Enter. Every key of a shortcut is checked, and shortcuts with Control, Alt or Command are checked like Enter.
- Agents can no longer type into a password or card field one key press at a time.
- Commands with a here-document or a comment are never treated as read-only, so they ask first in careful mode and aren't repeated after a crash.
- `uniq - out` and `xxd - out` (reading standard input, writing a file) are no longer treated as read-only, nor are `yq -s` and `tree -R`, which write files.
- Deleting the whole system or a home folder is blocked however rm's options are written (`rm -r -f ~`, `rm ~ -rf`, `rm --recursive /`).
- On the server: the cloud browser only takes commands from Wren itself, connected MCP servers with a token must use https, and saved keys are shown with less of them visible.
