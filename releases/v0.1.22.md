- When you unlink a computer, the tasks it was running or had queued now end as stopped. Before, they could stay stuck. This works for every version, since it happens on Wren's server.
- If Wren can't reach its server when you unlink, it now says so and keeps trying until this computer's sign-in is cancelled.
- A link that couldn't be saved on this computer is cancelled on the server too.
- Fixes for the agent browser and macOS file listings found in the latest security review.
