- Security: a command that names its program by a path (`./ls`, `/some/folder/cat`), changes `PATH` or loader variables, or picks its program from a variable is no longer treated as a harmless read-only command. Folders like `.` in your `PATH` are ignored for agent commands.
- Security: commands hidden inside double quotes (`"$(…)"`, `` "`…`" ``) or `$'…'` escapes are judged like any other command.
- Security: browser approvals now name the element through a handle Wren keeps to itself, which a web page can't copy or forge. A look-alike swapped in, or a form that now submits somewhere else, is refused.
- Security: before an update installs, Wren waits until every task, Claude Code or Grok Build process and command (including anything they started) has really stopped. If something won't stop, the update waits.
- Security: Wren's file helpers on macOS can only read the few system files they need to start. On Windows, file writes refuse links and junctions on the way and are checked before anything is written (a folder swapped at the very moment of creation can still leave an empty file outside; see the 0.1.10 notes).
- A message sent to Claude Code or Grok Build while it is still working is answered in the next turn, in the same conversation.
