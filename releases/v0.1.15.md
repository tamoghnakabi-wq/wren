- Grok Build: a run no longer waits forever when Grok stops answering or exits mid-task. Stop now ends it within a few seconds, and Grok is confirmed closed before the task reports how it ended.
- Browser: fields named like `otpCode` or `pinCode` count as one-time codes and PINs, so agents never type into them and their values stay hidden.
- Updates: opening Wren while an update is finishing no longer quits it by mistake, and an unrelated program that merely mentions the installer no longer blocks Wren from starting.
