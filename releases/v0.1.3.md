Security and reliability fixes from an independent code audit.

- Terminal commands on macOS can no longer read the rest of your home folder (only allowed folders, plus the settings and caches developer tools need).
- File tools can't be tricked into writing outside allowed folders through broken symlinks.
- Claude Code and Grok Build now respect this computer's terminal/browser switches and folder limits, and their commands ask for approval like unsandboxed ones.
- With remote approvals off, approvals are answered in a native Wren prompt on this computer (web pages can't approve for it).
- Password, card and one-time-code fields are never shown to the agent; key presses are checked against the focused element.
- Stop now halts between actions, and a cancelled run can't be revived by a late report.
- Updates: older releases are never installed, and the download is re-verified right before installing.
- Sign-in data is never stored without the system keychain; signing out of ChatGPT can't be undone by a refresh in progress.
- Images reach ChatGPT-plan and local models.
